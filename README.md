# 銘柄情報取得ツール

## 1. 概要

銘柄コード(例: 554A)または銘柄名を入れると、インターネットから **株価・PSR・自己資本比率・営業キャッシュフロー・有利子負債** を取得して一覧表示するツールです。複数の銘柄をまとめて調べられます。

取得元: 株探(株価・時価総額・売上高・自己資本比率・営業CF)、IR BANK または金融庁 EDINET(有利子負債 = 貸借対照表の借入金・社債などの合計)、金融庁 EDINET の会社一覧(銘柄名の検索)。

## 2. 必要な環境

- Windows 10 / 11
- Python 3.11 以上
- ライブラリ: 標準ライブラリだけ(追加のインストールは不要)
- インターネット接続
- (任意)EDINET の APIキー(無料)。無くても有利子負債は IR BANK から取得します

## 3. セットアップ手順

1. Python が入っているか確認します。

   ```
   py --version
   ```

2. (任意)EDINET の APIキーを取得します。入れると、有利子負債を金融庁の有価証券報告書から直接計算します(無いときは IR BANK を使います)。
   1. https://api.edinet-fsa.go.jp/api/auth/index.aspx?mode=1 を開き、案内に従ってアカウントを作成します。
   2. 表示された APIキー(Subscription-Key)をコピーします。
   3. ツールを起動し、「EDINETのAPIキーを設定」ボタンを押して貼り付け、「保存する」を押します。
      キーは `%LOCALAPPDATA%\銘柄情報取得\edinet_api_key.txt` に保存されます(Box には置きません)。

## 4. 実行方法

- `銘柄情報取得.pyw` をダブルクリックします。
- 入力欄に銘柄コードまたは銘柄名を入れ、「情報を取得する」を押します。複数のときは改行・カンマ・空白で区切ります(社名は空白を入れずに入力)。
- 表の行を選ぶと、下の欄に出典・計算方法・注意が出ます。
- コマンドで起動する場合:

  ```
  py 銘柄情報取得.pyw
  ```

1銘柄あたり3秒以上あけて取得します(相手のサイトに負担をかけないため)。
APIキーを入れた場合、有利子負債の初回は EDINET の提出書類を日付ごとにさかのぼって探すため、数分かかることがあります(2回目からは保存した一覧を使うので速くなります)。

### 表の項目

| 項目 | 内容 |
|---|---|
| 株価(円) | 株探の株価(15分遅れ) |
| 時価総額(億円) | 株探の時価総額 |
| PSR 実績/予想(倍) | 時価総額 ÷ 売上高(最新の通期実績/今期予想)。小数第2位で四捨五入 |
| 自己資本比率(%) | 最新の決算(四半期を含む)の値。詳細欄に通期の値も表示 |
| 営業CF(百万円) | 最新の通期の営業活動によるキャッシュ・フロー |
| 有利子負債(百万円) | 貸借対照表の、借入金・社債・コマーシャル・ペーパーを足したもの。リース債務は含めず、詳細欄に別に表示。取る順番: ①EDINET(APIキーがあるとき)②IR BANK ③株探の有利子負債倍率×自己資本の概算(「約」付き)④どれも無ければ「－」。詳細欄に何時点の数字か・元の資料を表示 |
| 結果 | 成功 / 一部取得できず / 要確認 / 失敗 |

### スマホで見る(GitHub Pages)

`銘柄リスト.txt` に書いた銘柄を、GitHub が平日の 12:05 と 15:50(日本時間。数分〜数十分遅れることがあります)に取得し、スマホ向けのページを作り直します。

**スマホ版は PC 版と中身が違います。** 株探・IR BANK は GitHub のサーバーからの取得を受け付けないため、スマホ版は金融庁 EDINET(公式の API)だけで作ります。

- 出る項目: 売上高・自己資本比率・営業CF・有利子負債(最新の有価証券報告書・半期報告書の数字。年2回ほど新しくなる)
- 出ない項目: 株価・時価総額・PSR(検索で確認するか、PC 版を使ってください)
- GitHub の Secrets に `EDINET_API_KEY` が必要です

- ページの URL: https://takagawa-glitch.github.io/investment/
- 銘柄を変えるとき: スマホの GitHub アプリ(またはブラウザ)で `銘柄リスト.txt` を開き、鉛筆マークで編集して保存(Commit)すると、数分でページが作り直されます。
- すぐ更新したいとき: GitHub の「Actions」→「銘柄情報を更新」→「Run workflow」。
- **ページは URL を知っていれば誰でも見られます**(検索サイトには載らない設定にしています)。リポジトリも公開なので、銘柄リストも見られます。
- 1回に取得するのは50銘柄までです(株探に負担をかけないため)。

初めて使うときの設定(1回だけ):

1. GitHub のリポジトリの「Settings」→「Pages」→「Build and deployment」の「Source」を **GitHub Actions** にする。
2. 「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で、Name に `EDINET_API_KEY`、Secret に EDINET の APIキーを入れて保存する(キーは公開されません)。

PC でページを試しに作る場合:

```
py build_site.py --list 銘柄リスト.txt --out site
```

## 5. 設定できる項目

| 名前 | 意味 | 既定値 | 必須か | 設定しないとき |
|---|---|---|---|---|
| EDINET の APIキー | 有利子負債を有価証券報告書から直接計算する | なし | 任意 | IR BANK の貸借対照表から計算する |
| 環境変数 `EDINET_API_KEY` | APIキー(GitHub の Secrets から渡す。PC では普通は使わない) | なし | 任意 | 上のファイルのキーを使う |
| 環境変数 `MEIGARA_DATA_DIR` | キャッシュの保存先(GitHub 用) | `%LOCALAPPDATA%\銘柄情報取得` | 任意 | 既定の場所を使う |
| `銘柄リスト.txt` | スマホ向けページに載せる銘柄(1行に1つ、`#` から後ろはメモ) | 554A | 任意 | 空ならページに「銘柄リストが空です」と出る |

PC で環境変数を試しに設定する例(コマンドプロンプト): `set EDINET_API_KEY=xxxx`

## 6. よくあるエラーと対処法

| 症状(画面に出るメッセージ) | 原因 | 対処 |
|---|---|---|
| 「銘柄情報取得を起動できませんでした」 | Box の同期中でファイルが壊れている・更新中など | 同期が終わるまで待って再起動。解決しなければ画面を撮影して担当者へ |
| 「株探に接続できませんでした」「EDINETに接続できませんでした」「IR BANKから取得できませんでした」 | インターネットにつながっていない、相手のサイトが混雑・停止中 | 接続を確認し、しばらくしてからもう一度 |
| 「株探にこの銘柄のページが見つかりませんでした」 | 銘柄コードの誤り、上場廃止 | 銘柄コードを確認 |
| 「候補が○件あります」(結果: 要確認) | 銘柄名で複数の会社が見つかった | 詳細欄の候補から銘柄コードを選んで入れ直す |
| 「EDINET の APIキーが正しくありません」 | キーの貼り付け間違い・期限切れ | 「EDINETのAPIキーを設定」から入れ直す |
| 「会社独自の項目を含めて合計しています」(結果: 要確認) | 会社が独自の科目名で借入金を載せている | 詳細欄の内訳を有価証券報告書と見比べる |
| 「より新しい書類のページが IR BANK で開けなかった」 | IR BANK 側のページの不具合 | 詳細欄の日付を確認。新しい数字が必要なら EDINET の APIキーを入れる |
| 「株探: 通期の業績の表が見つかりません」など | 株探のページの作りが変わった | 担当者へ連絡(プログラムの修正が必要) |
| スマホのページで全銘柄が「失敗」、株探に「応答コード 403」 | 株探が GitHub のサーバーからの取得を拒否している | PC 版は使えます。担当者へ連絡(取得方法の見直しが必要) |
| スマホのページが更新されない | GitHub Actions が失敗している(GitHub から通知メールが届く) | 「Actions」の画面で赤い×の実行を開き、担当者へ連絡 |
| 処理記録・エラー記録が保存されない | Box の同期中・ファイル使用中 | 取得は続けられます。気になる場合は時間をおいて再実行 |

エラーの詳細は `ログ\error_<PC名>.log`(書けないときは `%LOCALAPPDATA%\銘柄情報取得\error.log`)に記録されます。解決しないときは、画面を撮影して作成担当者(高閑者)に連絡してください。

## 7. 作られるファイル

| ファイル | 場所 | 内容 |
|---|---|---|
| 処理記録 | `処理記録\処理記録_YYYY-MM_<PC名>.log` | いつ・誰が・どの銘柄を取得し・どうなったか。1年を過ぎると起動時に自動で削除 |
| エラー記録 | `ログ\error_<PC名>.log` | エラーの詳細 |
| APIキー | `%LOCALAPPDATA%\銘柄情報取得\edinet_api_key.txt` | EDINET の APIキー(**他人に見せない**) |
| 一時保存 | `%LOCALAPPDATA%\銘柄情報取得\cache\` | 銘柄の一覧・EDINET の書類一覧・IR BANK の計算結果など。消しても次回取り直すだけ |
| スマホ向けページ | `site\index.html`(PC で試したとき)／GitHub Pages | 取得結果。**公開される** |

個人情報を含むファイルはありません(扱うのは公開されている株式・財務の情報だけです)。

※ 表示する数値は確認の補助です。投資の判断は、元の資料(決算短信・有価証券報告書)で確かめてください。
